
# Sistema de Reservas de Restaurante

Projeto acadêmico desenvolvido em grupo para a criação de um sistema de reservas de mesas em um restaurante.

## Tecnologias utilizadas

- PHP
- MySQL
- HTML e CSS (interface em desenvolvimento)

## Banco de dados

Nome: `RESTAURANTE_DB`

Tabelas:
- USUARIOS
- DIAS_FUNCIONAMENTO
- MESAS
- HORARIOS
- RESERVAS

## Funcionalidades previstas

- Cadastro e validação de usuários
- Consulta de mesas e horários
- Realização de reservas
- Alteração e cancelamento de reservas

## Como executar

1. Instale o PHP e o MySQL Server.
2. Crie o banco de dados `RESTAURANTE_DB`.
3. Configure a conexão local com o MySQL.
4. Execute o projeto usando o servidor PHP.

## Observação

Projeto desenvolvido para fins acadêmicos.
